# Backlog Inicial

## Prioridad alta

### Base de plataforma

- Configurar repositorio, estructura del proyecto y entornos.
- Definir modelo de datos inicial.
- Configurar autenticacion y roles.
- Crear layout base y navegacion principal.

### Proyectos

- Crear proyecto desde panel asesor/admin.
- Invitar cliente al proyecto.
- Vista general del proyecto con objetivo, progreso y sesiones.

### Kanban

- Crear tablero por proyecto.
- Crear columnas base.
- Crear, editar y mover tareas.
- Asignar responsable y fecha objetivo.
- Adjuntar evidencia simple a una tarea.

### Sesiones

- Crear paquetes de sesiones.
- Integrar compra con Stripe Checkout.
- Registrar saldo de sesiones comprado.
- Mostrar disponibilidad del asesor.
- Reservar una sesion.
- Crear evento con enlace de Google Meet.
- Cambiar estado de sesion: programada, realizada, cancelada.
- Guardar notas post sesion.

## Prioridad media

- Timeline de actividad del proyecto.
- Comentarios en tareas.
- Recordatorios por correo.
- Dashboard administrativo basico.
- Reprogramacion de sesiones.
- Vista de historial de compras.

## Prioridad posterior

- Integracion con Zoom.
- Asistente IA para resumen de sesiones.
- Plantillas de proyecto por tipo de servicio.
- Automatizaciones sugeridas por etapa.
- Reportes de productividad y conversion.

## Historias de usuario iniciales

1. Como cliente, quiero ver mi proyecto y sus tareas para entender el avance.
2. Como cliente, quiero comprar sesiones para continuar el acompañamiento.
3. Como cliente, quiero reservar una sesion con enlace listo para entrar.
4. Como asesor, quiero gestionar tareas por proyecto para organizar la ejecucion.
5. Como asesor, quiero dejar evidencia y notas para mostrar el progreso.
6. Como administrador, quiero monitorear proyectos, compras y sesiones para operar el servicio.
