# Roadmap MVP

## Fase 0 - Fundacion

Objetivo: convertir la idea en una base de producto consistente y lista para construir.

- Vision y alcance.
- PRD base.
- Modelo de datos inicial.
- Eleccion de stack.
- Definicion del flujo critico.

## Fase 1 - Workspace de proyecto

Objetivo: habilitar el trabajo colaborativo alrededor del proyecto.

- Autenticacion.
- Roles.
- Creacion de proyectos.
- Vista resumen de proyecto.
- Tablero Kanban base.

Resultado esperado: cliente y asesor ya pueden trabajar dentro del mismo proyecto.

## Fase 2 - Monetizacion y agenda

Objetivo: conectar el trabajo con la compra y reserva de sesiones.

- Paquetes de sesiones.
- Integracion Stripe.
- Saldo de sesiones.
- Agenda de disponibilidad.
- Reserva con Google Meet.

Resultado esperado: el cliente puede comprar y reservar trabajo sin salir de la plataforma.

## Fase 3 - Evidencia y trazabilidad

Objetivo: demostrar progreso y fortalecer la confianza del cliente.

- Evidencia por tarea.
- Comentarios.
- Notas de sesion.
- Timeline de actividad.
- Estado operativo de cada proyecto.

Resultado esperado: el proyecto deja una huella visible y facil de revisar.

## Fase 4 - Escalamiento

Objetivo: preparar la operacion para mas volumen y mejores resultados.

- Dashboard administrativo.
- Correos y recordatorios.
- Integracion Zoom.
- Resumenes asistidos por IA.
- Plantillas por tipo de proyecto.

## Orden recomendado de construccion

1. Proyecto y autenticacion.
2. Tablero Kanban.
3. Compra y reserva de sesiones.
4. Evidencia y notas.
5. Panel administrativo.

## Criterio de corte del MVP

No avanzar a funcionalidades avanzadas hasta validar que el flujo principal genera:

- compras reales,
- sesiones efectivamente realizadas,
- tareas con evidencia,
- percepcion clara de avance por parte del cliente.
